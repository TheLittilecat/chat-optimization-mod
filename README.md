# Chat Optimization Mod / 聊天优化 Mod

[English](#english) | [中文](#中文)

---

## English

This mod lets you add various chat optimization options. The specific commands are listed below:

### Commands

| Command | Description |
|---|---|
| `/tlc` or `/tlc help` | View help for all commands |
| `/tlc plan add <planName>` | Create a new empty plan |
| `/tlc plan set <planName>` | Switch to the active plan |
| `/tlc plan remove <planName>` | Remove a plan |
| `/tlc rule add <originalText> <replacementText>` | Add a replacement rule to the current plan |
| `/tlc rule list` | List all replacement rules in the current plan |
| `/tlc rule remove <originalText>` | Remove a rule by its original text |
| `/tlc last add <text>` | Append content to the end of the current plan |
| `/tlc last list` | List all trailing append entries in the current plan |
| `/tlc last remove <text>` | Remove a trailing append entry by its text |

> **Tip:** All changes apply to the currently selected plan. This mod comes with one built-in plan (Chinese).
> **Tip:** When multiple rules are added for the same original text, a random one will be selected each time you send a message.

Have fun!

## 中文

本 Mod 允许你添加各种聊天优化选项。具体命令如下：

### 命令

| 命令 | 说明 |
|---|---|
| `/tlc` 或 `/tlc help` | 查看所有命令的帮助 |
| `/tlc plan add <方案名>` | 新建一个空方案 |
| `/tlc plan set <方案名>` | 切换到指定方案 |
| `/tlc plan remove <方案名>` | 删除一个方案 |
| `/tlc rule add <原文本> <替换为>` | 在当前位置方案的替换规则 |
| `/tlc rule list` | 列出当前方案的所有替换规则 |
| `/tlc rule remove <原文本>` | 按「原文本」删除规则 |
| `/tlc last add <文本>` | 给当前位置方案的末尾追加内容 |
| `/tlc last list` | 列出当前的末尾追加内容 |
| `/tlc last remove <文本>` | 删除某条末尾追加 |

> **提示：** 所有更改都会应用到当前选中的方案。本 Mod 内置了一个默认方案（中文）。
> **提示：** 当同一段原文本添加了多条规则时，每次发送消息时会随机选择一条生效。

快去试试吧！
